# International Student Simulator — Start Page & Character Selection

This package contains the start page and the character selection page for **International Student Simulator**.

## Pages / Routes

| Page | Route | Description |
|---|---|---|
| Home Page | `/` | Start page with title, Start Game, About Us, and Sign In buttons |
| Character Selection | `/characters` | Choose one of four starting characters |

## Character Options

- Academic Star
- Rich Kid
- Fitness Lover
- Ordinary Student

## How to Run

```bash
cd frontend
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173/
```

You can also directly open:

```text
http://localhost:5173/characters
```

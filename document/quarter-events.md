# Quarter Events

## 1. Core Gameplay Rule

The game is divided into four quarters.  
Each quarter has a different story theme and a different event pool.

In each quarter, the player chooses **any 3 planned events** from three categories:

- Study
- Entertainment
- Social

The player does **not** have to choose one event from each category.  
For example, the player can choose:

| Example Choice | Meaning |
|---|---|
| 3 Study events | A study-focused quarter |
| 2 Study + 1 Entertainment | A mostly academic quarter with some rest |
| 1 Study + 1 Entertainment + 1 Social | A balanced quarter |
| 3 Entertainment events | A recovery or relaxed quarter |
| 3 Social events | A social and networking-focused quarter |

After the player chooses 3 planned events, the system adds **1 random event** for that quarter.

So each quarter contains:

| Event Type | Number |
|---|---:|
| Player-chosen planned events | 3 |
| Random life event | 1 |
| Total events per quarter | 4 |

After all four quarters, the player has experienced 16 events in total.

## 2. Attribute System

The game has three core attributes:

| Attribute | Meaning |
|---|---|
| Intelligence | Academic ability, learning progress, planning, and career preparation |
| Health | Physical health, mental wellbeing, stress level, and lifestyle balance |
| Wealth | Money, savings, budgeting, financial stability, and future income opportunity |

Recommended hidden value range:

| Value Range | Display Level |
|---:|---|
| 0–44 | Poor |
| 45–84 | Average |
| 85–100 | Excellent |

The page may display only the level to the player.  
The hidden numbers are used by the system for calculation.

## 3. Value Change Scale

The value changes are designed to feel more meaningful than only +1 or -1.

| Impact Level | Value Change | Example |
|---|---:|---|
| Small | ±2 to ±3 | Small habit, small social activity |
| Medium | ±4 to ±6 | Normal study, entertainment, or social event |
| Large | ±7 to ±10 | Important exam, big trip, work shift, crisis |
| Critical | ±11 to ±12 | Final exam sprint, major recovery, important career event |

## 8. Quarter Summary Page

After each quarter, the game should show:

- Events completed this quarter
- Player choices
- Attribute changes
- Current attribute levels
- A short story summary

Suggested format:

| Section | Example |
|---|---|
| Quarter Result | Quarter 2 Summary |
| Choices | Midterm Revision Plan, Gym Stress Relief, Flatmate Dinner, Library All-nighter |
| Attribute Change | Intelligence +13, Health -5, Wealth +3 |
| Current Status | Intelligence: Average, Health: Poor, Wealth: Average |
| Story Summary | This quarter was academically intense, but you still tried to protect your health. |

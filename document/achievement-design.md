# Achievement Design

> Source: Achievement.docx, updated to use the final category system discussed for the database and UI.

## Category System

Only four achievement categories are used in the current implementation:

- **Intelligent**: study, course, academic planning, exam, or file organisation achievements.

- **Health**: health, lifestyle, leisure, social, emotional, and wellbeing-related achievements.

- **Wealth**: money, budgeting, work, savings, and financial achievements.

- **Crown**: ultimate combined achievement only.
